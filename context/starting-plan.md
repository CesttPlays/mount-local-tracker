Briefing — mount-local-tracker

Purpose

A World of Warcraft addon, "Mount Tracker: Local Zones", that puts a small window on screen listing the mounts you can still collect in the zone you're standing in — dungeon/raid drops for instances there, rare-mob drops, vendor mounts, quest rewards, zone drops, world-event mounts. The list follows you as you change zones. Collect a mount and its row updates.

It is the sibling of achivement-local-tracker (same solo dev, built first). That repo is the reference implementation for architecture, headless tests, CI, and the release pipeline — this project mirrors all of it with C_MountJournal in place of the achievement API.

Two design pillars:
1. Zone-scoped — the addon's identity. Not a full collection browser (that's what MissingMounts and the Mount Journal already do).
2. Obtainability-aware — inspired by MissingMounts: don't just say "you're  can buy it right now for 5,000g from an NPC in this zone" or "you're 2,400rep from unlocking it" or "that farm resets weekly and you haven't run it."

Publishing target: CurseForge / WoWInterface. Code kept release-quality (no debug spam, sane defaults, saved-variable hygiene).
